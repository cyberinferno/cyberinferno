<h1 align="center">Hi 👋, I'm Karthik</h1>
<p align="center">Software engineer building high performance backend systems for large-scale video streaming as well as transportation services. Outside work I tinker with game servers, networking, and developer tools.</p>

## 🛠️ What I work on

- GraphQL backend-for-frontend layers that power web, mobile, and TV apps
- Core platform services: entitlements and subscriptions, watchlists and continue watching, search and recommendations
- Event-driven pipelines and content distribution: partner catalog feeds, SEO sitemaps, CDN-delivered config
- Performance and reliability work: caching, circuit breakers, shared Go libraries, data migrations, plus functional and load testing
- Game server emulators and low-latency socket libraries
- Network protocol analysis tools: packet loggers, sniffers, Wireshark dissectors
- Community tooling for online games: Discord bots, game updaters, admin panels, and a guide site
- Small utilities and starter templates: Cloudflare DDNS, port monitoring, API boilerplates
